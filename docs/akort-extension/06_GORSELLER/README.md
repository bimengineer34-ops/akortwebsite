3. `03_AI_Icerik_Studyosu.png` = GPT/Claude/Gemini metin ve görsel üretim editörü.
4. `04_Brand_Kit_Tasarim_Sistemi.png` = Logo, renk, typography, onaylı şablonlar.
5. `05_Onay_Performans_Merkezi.png` = Kanban onay iş akışı + platform analitiği.
