# AI Content Studio
- Sağlayıcı kayıtları OpenAI / Anthropic / Google Gemini; provider adapter, model katalog sorgusu/konfigürasyonu, test bağlantısı, kullanım/kota/maliyet, timeout/retry/circuit breaker, güvenli anahtar yönetimi.
- Üretim: sıfırdan blog/hizmet/proje taslağı; seçili paragrafı yeniden yaz, kısalt/genişlet/çevir, dil profesyonelliği, title/meta alternatifleri, SEO-uyum analizi, marka tonu.
- Editör seçili metin operasyonları ve track changes; sonuç kullanıcı kabul etmeden kaydedilmez; model çıktısı güvenilmez HTML olarak render edilmez, XSS temizliği zorunlu.
- Multi-model comparison isteğe bağlı, default tek çağrı; token/cost tahmini ve kişi başı limitler.
- Teknik iddialarda kaynak ID, yayımlanma tarihi, doğrulanmamış işaretleme ve insan incelemesi.
- Onaylı Brand Kit, editör roller, taslak versiyonlama, audit trail, kaynak ve prompt geçmişi.
- Test: provider offline/rate-limit, yanlış key, maliyet sınırı, XSS, veri gizliliği, kısmi hata, onay/revizyon.
