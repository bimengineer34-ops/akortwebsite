# Dış servis entegrasyonları ve sınırları
- OpenAI/Anthropic/Gemini: API keys and models availability may change; use official SDK supported by existing stack; cost/limits and logging. Keys server only.
- Google Search Console: Search Analytics, URL Inspection (quota limited), sitemap actions; property verified by user. Indexing API NOT for general service/blog pages; no guarantee of instant indexing or ranking.
- GA4: consent-appropriate reporting setup. Site metrics versus estimated competitor metrics distinguished.
- Google Business Profile: only supported and approved access/features. Profile eligibility required.
- Social OAuth: only authorized accounts; feature matrix per platform/country/account; official API documentation checked at integration time. Don't promise unsupported story/video/carousel automation.
- SERP/backlink: external permitted data provider optional; limited coverage without subscription; transparent unknowns.
- News/RSS: provenance, content rights and attribution. Do not store/repost full copyrighted articles unnecessarily.
- CDN/hosting: server-level controls may require Veridyen plan or proxy/CDN permissions; unsupported options visibly unavailable.
